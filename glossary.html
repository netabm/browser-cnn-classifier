Below are 44 key terms appearing in the code and underlying neural network theory:

Term Category Explanation and Meaning in Code
CNN (Convolutional Neural Network) Architecture A neural network designed for processing structured array data, such as image pixels, using local filtering layers.
Convolution Architecture A mathematical operation where a filter slides over an input matrix to detect spatial features like edges or shapes.
Filter / Kernel Architecture A small matrix of weights (e.g., 3x3) applied during convolution to extract specific features from the input.
Feature Map Architecture The 2D output matrix resulting from applying a single filter across the input image.
Pooling Architecture A downsampling operation used to reduce the spatial dimensions (width and height) of feature maps.
Max Pooling Architecture A specific pooling type that extracts only the maximum value within a window (e.g., 2x2), providing translation invariance.
Neuron / Node Architecture A single computational unit in a neural network that receives inputs, multiplies them by weights, adds a bias, and passes the result to an activation function.
Dense Layer (Fully Connected) Architecture A standard neural network layer where every neuron is connected to all neurons in the previous layer. Used for final classification.
Flatten Layer Architecture A layer that takes multi-dimensional tensors (e.g., 3D feature maps) and reshapes them into a 1D array for the Dense layer.
Stride Architecture The number of pixels a filter or pooling window moves across the input matrix at each step.
Padding Architecture Adding extra pixels (usually zeros) around the border of an input matrix to control the spatial size of the output feature map.
Input Layer Architecture The initial layer of the network that receives raw data (in our case, the 28x28 normalized canvas pixels).
Output Layer Architecture The final layer that produces the model's predictions (in our case, 3 neurons for Circle, Square, and Triangle).
Receptive Field Architecture The specific region in the input image that a particular CNN feature is looking at.
Activation Function Math & Activations A mathematical equation attached to a neuron that determines whether it should be activated, introducing non-linearity to the model.
ReLU (Rectified Linear Unit) Math & Activations An activation function that outputs the input directly if it is positive, and outputs zero if it is negative [f(x) = max(0, x)].
Softmax Math & Activations An activation function used in the output layer to convert raw logits into a probability distribution summing to 1 (100%).
Dot Product Math & Activations The algebraic operation of multiplying matching elements from two matrices/vectors and summing the results.
Matrix Multiplication Math & Activations A core operation in neural networks where matrices of inputs and weights are multiplied to compute layer outputs.
Logits Math & Activations The raw, unnormalized scores outputted by the final Dense layer before they are passed into the Softmax function.
Exponential Function (exp) Math & Activations Used inside Softmax to exaggerate differences in logits, pushing the highest value closer to 1 and smaller values toward 0.
Tensor Math & Activations A multi-dimensional array of numbers (e.g., the 3D arrays holding our feature maps are tensors).
Numerical Stability Math & Activations Mathematical tricks (like subtracting the max value before Softmax) used in programming to prevent numbers from becoming too large (Infinity) or too small (NaN).
Forward Pass Training Terms The process of pushing input data through the network layers from start to finish to generate a prediction.
Backpropagation Training Terms The algorithm used to compute the gradient of the loss function, distributing the error backwards to update the network weights.
Weights Training Terms The learnable parameters inside filters and dense layers that determine the strength of connections between neurons.
Biases Training Terms Learnable constant values added to the dot product of inputs and weights, allowing the activation function to shift.
Learning Rate Training Terms A hyperparameter that controls how much to change the model in response to the estimated error each time the model weights are updated.
Loss / Cost Function Training Terms A mathematical method of evaluating how well the specific algorithm models the given data (how far predictions are from reality).
Categorical Cross-Entropy Training Terms The specific loss function used for multi-class classification, heavily penalizing predictions that are confident but wrong.
Epoch Training Terms One complete pass of the training dataset through the neural network algorithm.
Batch / Batch Size Training Terms A set of multiple samples processed together before updating weights (In our manual implementation, batch size is effectively 1).
Accuracy Training Terms A metric measuring the percentage of correct predictions out of all predictions made.
Overfitting Training Terms When a model learns the training data too well, capturing noise instead of general patterns, leading to poor performance on new data.
Gradient Training Terms A vector indicating the direction and rate of fastest increase of the loss function. We step in the opposite direction to minimize loss.
Gradient Descent Training Terms The optimization algorithm used to minimize the loss function by iteratively moving in the direction of steepest descent.
Underfitting Training Terms When a model is too simple or hasn't trained long enough to capture the underlying trend of the data.
Convergence Training Terms The state during training when the loss stops decreasing significantly, meaning the model has settled on its final parameters.
Argmax Training Terms The mathematical operation used at the end of predictions to find the index (class) associated with the highest probability.
Canvas API Web & Implementation A JavaScript feature used to draw graphics on a web page. Used in this project to capture user drawings.
Grayscale Normalization Web & Implementation The process of converting colored pixels to a single intensity value, and scaling it between 0.0 and 1.0 for neural network input.
LocalStorage Web & Implementation A web storage object allowing JavaScript sites to store key/value pairs in a web browser with no expiration date (used to save model weights).
JSON Serialization Web & Implementation Converting complex JavaScript objects (like multidimensional weight arrays) into a string format (JSON) so they can be saved in LocalStorage.
Event Listener Web & Implementation A procedure in JavaScript that waits for an event to occur (like a mouse click or drawing on the canvas) to trigger functions.
